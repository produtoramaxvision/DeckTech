# Aviso de Privacidade / Privacy Notice

Vigência: 27 de setembro de 2026.

## Português

O responsável por este aviso é Produtora MaxVision, CNPJ 38.386.434/0001-44, Diadema/SP.

O DeckTech funciona prioritariamente na rede local, sem conta e sem telemetria da Produtora MaxVision. O host guarda a configuração principal, o PIN e a chave privada TLS. Os clientes recebem os dados necessários ao painel e guardam a sessão; o Android também guarda o endereço do host e a impressão digital do certificado. A chave privada TLS não é enviada aos clientes. Esses dados trafegam somente entre os dispositivos que você conectar à sua rede local.

Para verificar e baixar atualizações, o DeckTech acessa o GitHub. O GitHub pode registrar dados técnicos da conexão, como endereço IP, data, hora e agente do usuário, atuando como controlador independente conforme sua [Declaração de Privacidade](https://docs.github.com/pt/site-policy/privacy-policies/github-general-privacy-statement). A Produtora MaxVision não recebe esses registros de forma individualizada.

Ao exibir atalhos de sites, o painel móvel pode consultar diretamente o serviço de ícones do Google, enviando o domínio, ou os assets do GitHub para atalhos do GitHub; o ícone do próprio site é uma alternativa. No macOS, o DeckTech também pode consultar a página do site e os endereços de ícones/CDNs indicados por ela. Essas conexões partem do dispositivo que carrega os ícones e podem enviar o endereço do site ou o domínio, além de dados técnicos da conexão, ao respectivo provedor, conforme as políticas de privacidade dele. No host Windows, os atalhos de sites usam monogramas, sem essas consultas.

Ao abrir Issues, Discussions ou relatos privados de vulnerabilidade, você fornece ao GitHub e aos mantenedores o conteúdo e os dados de perfil que decidir publicar. Não inclua PINs, certificados privados, tokens, senhas, endereços pessoais ou logs não revisados.

Para dúvidas sobre privacidade, escreva para [contato@decktech.com.br](mailto:contato@decktech.com.br) e identifique a mensagem como assunto de privacidade.

## English

The party responsible for this notice is Produtora MaxVision, CNPJ 38.386.434/0001-44, Diadema/SP.

DeckTech operates primarily on the local network, with no account and no Produtora MaxVision telemetry. The host stores the main configuration, the PIN, and the TLS private key. Clients receive the data the deck needs and retain their session; Android also stores the host address and certificate fingerprint. The TLS private key is not sent to clients. That data travels only among devices you connect to your local network.

DeckTech contacts GitHub to check for and download updates. GitHub may log technical connection data, including IP address, date, time, and user agent, acting as an independent controller under its [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Produtora MaxVision does not receive those records individually.

When displaying website shortcuts, the mobile deck may contact Google's favicon service directly, sending the domain, or GitHub assets for GitHub shortcuts; the site's own favicon is a fallback. On macOS, DeckTech may also request the site's page and the icon/CDN URLs it specifies. These connections originate from the device loading the icons and may send the site address or domain, along with technical connection data, to the respective provider, under its own privacy policy. The Windows host uses monograms for website shortcuts, with no such requests.

When you open Issues, Discussions, or private vulnerability reports, you provide GitHub and the maintainers with the content and profile data you choose to publish. Do not include PINs, private certificates, tokens, passwords, personal addresses, or unreviewed logs.

For privacy questions, email [contato@decktech.com.br](mailto:contato@decktech.com.br) and identify the message as a privacy matter.
