# Privacy Notice

Effective: September 27, 2026.

The party responsible for this notice is Produtora MaxVision, CNPJ 38.386.434/0001-44, Diadema/SP.

DeckTech operates primarily on the local network, with no account and no Produtora MaxVision telemetry. The host stores the main configuration, the PIN, the TLS private key and, if you set one, the OBS WebSocket password (in `.obs-password`, readable only by your user account). The OBS password is never sent back to clients. Clients receive the data the deck needs and retain their session; Android also stores the host address and certificate fingerprint. The TLS private key is not sent to clients. That data travels only among devices you connect to your local network.

DeckTech contacts GitHub to check for and download updates. GitHub may log technical connection data, including IP address, date, time, and user agent, acting as an independent controller under its [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Produtora MaxVision does not receive those records individually.

When displaying website shortcuts, the mobile deck may contact Google's favicon service directly, sending the domain, or GitHub assets for GitHub shortcuts; the site's own favicon is a fallback. On macOS, DeckTech may also request the site's page and the icon/CDN URLs it specifies. These connections originate from the device loading the icons and may send the site address or domain, along with technical connection data, to the respective provider, under its own privacy policy. The Windows host uses monograms for website shortcuts, with no such requests.

When you open Issues, Discussions, or private vulnerability reports, you provide GitHub and the maintainers with the content and profile data you choose to publish. Do not include PINs, private certificates, tokens, passwords, personal addresses, or unreviewed logs.

For privacy questions, email [contato@decktech.com.br](mailto:contato@decktech.com.br) and identify the message as a privacy matter.
