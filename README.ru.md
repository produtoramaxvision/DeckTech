<h1 align="center">DeckTech</h1>

<p align="center"><a href="README.md">English</a> | <a href="README.pt-BR.md">Português (Brasil)</a> | <a href="README.es.md">Español</a> | <strong>Русский</strong> | <a href="README.zh-CN.md">简体中文</a></p>

DeckTech превращает Mac или компьютер с Windows в хост удалённой док-панели приложений. Приложение запускает локальный сервер Node.js и предоставляет свой интерфейс устройствам в той же сети через Android-приложение (APK), PWA на iPhone или браузер.

Это руководство относится к DeckTech v0.1.1.

В этом публичном репозитории размещены только документация, поддержка сообщества и официальные релизы. DeckTech — проприетарное программное обеспечение, его исходный код не публикуется.

Ответственная сторона и лицензиар: Produtora MaxVision, São Paulo/Brasil.

> Это русский перевод англоязычной документации. Интерфейс DeckTech сейчас существует на португальском (Бразилия) и английском языках, русского интерфейса нет. В Windows окно хоста в этой версии только на португальском; в macOS у хоста есть переключатель языка (Português/English); приложение для Android и PWA используют португальский, если язык устройства начинается с «pt», и английский во всех остальных случаях. Поэтому на устройстве с русским языком вы увидите английский интерфейс, кроме окна хоста в Windows — оно на португальском. Названия кнопок, вкладок и меню приложения указаны здесь так, как их показывает само приложение.

## Установка и первый запуск

### Windows

1. Скачайте и запустите `DeckTech-Setup.exe`.
2. Текущий установщик не подписан. Если появится Microsoft Defender SmartScreen, убедитесь, что файл получен из этого репозитория и его SHA-256 совпадает; выбирайте **More info** и **Run anyway** только если принимаете риск. Если в Windows выбран другой язык, SmartScreen покажет эти названия в переводе.
3. При первом запуске DeckTech показывает лицензионное соглашение (EULA): установите флажок согласия, чтобы активировать **Accept and start**, или выберите **Decline and quit**, чтобы закрыть приложение. Отказ не запоминается: соглашение будет показано снова при следующем запуске, а приложение останется установленным, пока вы не удалите его в **Settings > Apps**. Если язык вашей системы — португальский, подписи кнопок будут на португальском (**Aceitar e começar** / **Recusar e sair**).
4. Для DeckTech нужна Windows 10 или 11 (64 бита, x64, сборка 10240 или новее); установщик отказывается работать на более ранних версиях и в 32-битной Windows. Интерфейс хоста в Windows в этой версии только на португальском: на его вкладке **Conectar** (Connect) показаны локальный адрес и шестизначный код доступа — адрес появляется здесь, только если компьютер подключён к локальной сети (Wi-Fi или Ethernet), а не только к VPN.

### macOS

1. Скачайте `DeckTech-macOS.dmg`, откройте образ и перетащите DeckTech в **Applications**.
2. Приложение подписано по схеме ad hoc и не нотаризовано. Щёлкните **DeckTech** с зажатой клавишей Control, выберите **Open** и подтвердите. Если Gatekeeper блокирует запуск, попробуйте один раз и используйте **System Settings > Privacy & Security > Security > Open Anyway**. Эти названия macOS отображаются на языке вашей системы.
3. При первом запуске примите лицензионное соглашение (EULA), которое показывается перед главным окном.
4. Откройте вкладку **Connect**, чтобы увидеть локальный адрес и код доступа. В отличие от Windows, в приложении для macOS на этой же вкладке есть переключатель языка (Português/English), и подписи следуют выбранному там языку.

### Android

1. Скачайте `decktech.apk` из этого репозитория и разрешите установку из браузера, когда Android об этом спросит.
2. При первом запуске примите лицензионное соглашение (EULA), которое показывается в приложении.
3. На хосте с Windows или macOS откройте **Connect > Android app** (в Windows: **Conectar > App Android**) и отсканируйте QR-код камерой телефона. После этого APK доверяет только HTTPS-сертификату этого компьютера. Компьютер и телефон должны находиться в одной локальной сети (LAN) или в одной сети Tailscale; ссылка для сопряжения, указывающая куда-либо ещё, отклоняется из соображений безопасности (см. [Устранение неполадок в SUPPORT.ru.md](SUPPORT.ru.md#устранение-неполадок)).
4. Когда приложение находит компьютер автоматически, оно показывает 16-символьный код безопасности (`XXXX-XXXX-XXXX-XXXX`). Подтверждайте, только если он совпадает символ в символ с **Security code** (в Windows: **Código de segurança**) на вкладке **Connect** хоста.
5. Введите шестизначный код доступа. Если сертификат компьютера изменится, приложение попросит подтвердить снова. Если вы открываете ссылку для сопряжения вне приложения (через камеру, браузер или другое приложение), DeckTech запросит дополнительное подтверждение перед подключением (единственное исключение — ссылка, идентичная уже сохранённому в приложении подключению); подтверждайте, только если ссылку только что открыли или отсканировали именно вы.

### iPhone, iPad и браузеры

1. На хосте откройте **Connect > Browser** (в Windows: **Conectar > Navegador**).
2. Отсканируйте локальный HTTP-адрес или введите его в Safari либо другом браузере.
3. Введите шестизначный код доступа. В Safari используйте **Share > Add to Home Screen**, чтобы установить PWA.

Подключение через браузер использует HTTP в локальной сети. Используйте PWA только в доверенной локальной сети: код доступа управляет доступом, но HTTP не может помешать другому участнику сети наблюдать за трафиком или изменять его. На Android всегда отдавайте предпочтение закреплённому HTTPS-сценарию через QR-код **Android app**.

## OBS Studio

Панель **OBS Commander** умеет переключать сцены, запускать и останавливать запись и трансляцию, а также закреплять сцены в док-панели с помощью звёздочки рядом с каждой сценой. Запускайте OBS на том же компьютере, где работает DeckTech.

1. В OBS откройте **Tools › WebSocket Server Settings** (OBS показывает эти названия на своём языке).
2. Установите флажок **Enable WebSocket server** и укажите **Server Port: 4455**.
3. Оставьте включённым **Enable Authentication** и нажмите **Show Connect Info**.
4. Скопируйте пароль, вставьте его в панель OBS в DeckTech и нажмите **Save and connect**.

DeckTech подключается и при отключённой аутентификации OBS, но мы рекомендуем оставить её включённой. Сохранённый пароль хранится только на компьютере-хосте, в файле `.obs-password`; он никогда не возвращается на телефон в ответах API и в потоке WebSocket. Если вы вводите его на телефоне, при сохранении он отправляется на хост; для такой настройки лучше использовать Android с HTTPS. Файл защищён ACL только для владельца в Windows и правами `0600` в macOS; DeckTech заново применяет эту защиту при запуске. Ошибки ACL записываются в журнал, а администратор может вернуть себе доступ к файлу.

Если подключиться не удаётся, проверьте, что OBS запущен и его сервер WebSocket включён. При **неверном пароле** снова скопируйте текущий пароль из OBS и сохраните его. Если порт отличается от **4455**, измените его в настройках OBS. Правило брандмауэра для связи DeckTech с OBS не требуется: она остаётся локальной, по адресу `127.0.0.1` на том же компьютере (это не меняет сетевые требования между телефоном и DeckTech).

## Проверка контрольных сумм

Скачайте файл и `SHA256SUMS.txt` в одну папку, затем сравните хеш файла с соответствующей строкой:

```powershell
certutil -hashfile DeckTech-Setup.exe SHA256
```

```sh
shasum -a 256 DeckTech-macOS.dmg
sha256sum decktech.apk
```

[`DeckTech-macOS.dmg.sha256`](https://github.com/produtoramaxvision/DeckTech/releases/latest/download/DeckTech-macOS.dmg.sha256) также позволяет проверить именно DMG.
