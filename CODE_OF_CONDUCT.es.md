# Código de conducta

Este espacio está pensado para las personas que instalan, usan y participan en los Issues y las Discussions de DeckTech.

Comunícate con claridad y respeto. Las críticas deben referirse al producto y a las ideas, nunca a la persona. No se aceptan el acoso, la discriminación, las amenazas, la divulgación de datos personales ni el contenido abusivo.

Los mantenedores pueden editar o eliminar contenido, cerrar conversaciones y bloquear a participantes para proteger a la comunidad. Comunica de forma privada cualquier problema de conducta a [contato@decktech.com.br](mailto:contato@decktech.com.br), con el asunto Conducta.
