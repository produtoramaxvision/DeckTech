# Aviso de Privacidade

Vigência: 27 de setembro de 2026.

O responsável por este aviso é Produtora MaxVision, CNPJ 38.386.434/0001-44, Diadema/SP.

O DeckTech funciona prioritariamente na rede local, sem conta e sem telemetria da Produtora MaxVision. O host guarda a configuração principal, o PIN, a chave privada TLS e, se você configurar, a senha do WebSocket do OBS (em `.obs-password`, legível só pela sua conta de usuário). A senha do OBS nunca é devolvida aos clientes. Os clientes recebem os dados necessários ao painel e guardam a sessão; o Android também guarda o endereço do host e a impressão digital do certificado. A chave privada TLS não é enviada aos clientes. Esses dados trafegam somente entre os dispositivos que você conectar à sua rede local.

Para verificar e baixar atualizações, o DeckTech acessa o GitHub. O GitHub pode registrar dados técnicos da conexão, como endereço IP, data, hora e agente do usuário, atuando como controlador independente conforme sua [Declaração de Privacidade](https://docs.github.com/pt/site-policy/privacy-policies/github-general-privacy-statement). A Produtora MaxVision não recebe esses registros de forma individualizada.

Ao exibir atalhos de sites, o painel móvel pode consultar diretamente o serviço de ícones do Google, enviando o domínio, ou os assets do GitHub para atalhos do GitHub; o ícone do próprio site é uma alternativa. No macOS, o DeckTech também pode consultar a página do site e os endereços de ícones/CDNs indicados por ela. Essas conexões partem do dispositivo que carrega os ícones e podem enviar o endereço do site ou o domínio, além de dados técnicos da conexão, ao respectivo provedor, conforme as políticas de privacidade dele. No host Windows, os atalhos de sites usam monogramas, sem essas consultas.

Ao abrir Issues, Discussions ou relatos privados de vulnerabilidade, você fornece ao GitHub e aos mantenedores o conteúdo e os dados de perfil que decidir publicar. Não inclua PINs, certificados privados, tokens, senhas, endereços pessoais ou logs não revisados.

Para dúvidas sobre privacidade, escreva para [contato@decktech.com.br](mailto:contato@decktech.com.br) e identifique a mensagem como assunto de privacidade.
